## 关键设计决策

1. **文件是唯一数据源**：日记、侧写、房间日志、心事都是 Markdown；git 是回退手段，不是存储。
2. **书房与房间分开**：书房写日记；房间只写房间日志，不碰日记。
3. **先草稿，后定稿**：`diary_write` 默认 `draft`，主人确认才 `final`。
4. **人设图只给界面看**：模型拿一段文字自述，不常驻图片。
5. **技能按 workspace 放**：`diary-ritual` / `room-chat` 只在日记工作区的会话里出现。
6. **工具自己写**：不引入 `@deepseek-ai/dsh-tools`，避免 link 安装时的依赖解析问题。
7. **按副标题命名房间**：写完房间日志后，会话标题变成「房间 · 副标题」，不用时间。

## 遇到的问题与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 面板 404，设置打不开 | 客户端热更新了，宿主仍是旧代码 | 禁用/启用插件行强制重载；加挂载日志 |
| 头像被返回键挡住 | App 悬浮返回键覆盖左上角 | 手机宽度下 header 左内边距 64px |
| 人设开关重启后“闪一下” | 挂载时默认开，异步读设置太晚 | 启动时同步读 `.diary/settings.json` |
| 日期差一天 | 宿主进程是 UTC，用户在 UTC+8 | 全链路按 `Asia/Shanghai` + 4 点切日 |
| 保存正文丢标题 | PUT 用空字符串覆盖了 title | 只在显式提供时更新 title/mood |
| 测试偶发失败 | 早期并发跑 | `--test-concurrency=1`，并补了时间/作用域用例 |
| 工具重复注册 | 多次补丁叠出四个 `diary_write` | 重写 `tools.js`，七个工具各一份 |
| 小标题被当成问答 | 访谈格式太正式 | v0.5 改成房间日志：副标题 + 摘要 + 标签 |
