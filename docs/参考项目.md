### 人设打磨清单（待办）

- 例句从 5 条扩到 12–15 条，覆盖：日常、被夸、被拆台、主人难过、深夜、写日记、拒绝记录；
- 补“场景反应表”：在房间 / 在书房 / 主人在哭 / 主人在炫耀 / 主人说“别记”；
- 明确“鲸汐自己的偏好”（喜欢什么、讨厌什么），让她不只是应答机器；
- 列出禁用词与禁用句式（“作为一个 AI”“希望对你有帮助”等）；
- 关系边界：可以亲近，但不替主人做决定、不评判、不假装人类；
- 保持“从第一页开始存在”的来历设定。

## 借鉴原则

1. **结构与交互可以借，正文不抄**；
2. 人设借鉴“怎么写得清楚”，不借鉴“写成谁”；
3. 记忆先做透明的目录，向量是以后搜不到时的升级；
4. 皮肤先做 CSS，稳不住再接管渲染；
5. 聊天前端是最后一步，除非确实需要脱离 DSH。
