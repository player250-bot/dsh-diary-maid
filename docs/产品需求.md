# 产品需求（第一阶段定稿）

> 这是主人需求的“单一真相”。新会话先读这份，再读交接文档；实现有冲突时以这份为准。
> 来源：2026-10-23 ～ 10-26 的对话，已在 P0 落地部分打勾。

## 一句话

把 DSH 变成鲸汐的书房和房间：**主人讲，鲸汐记**；日记是主人的，侧写是鲸汐的观察，房间是她自己的地方。

## 核心需求

### 1. 日记是聊出来的，不是填表填出来的（已实现）

- 主人跟鲸汐讲今天，她作为**书记员**追问细节、记原话，最后转述成**第一人称“我”（主人）**的一页。
- 不是让主人在面板里自己写；面板是“书”，用来读、改错字、翻历史。
- 只写主人说过的事；拿不准就留白（“这里鲸汐没听清”）。
- 先草稿，主人确认后才定稿。

### 2. 三个产物，三种声音（已实现）

| 产物 | 人称 | 说明 |
| --- | --- | --- |
| 今日日记 | 第一人称“我” | 300–800 字，平实、保留原话，不美化 |
| 主人侧写 | 第三人称“主人” | `[事实]`/`[推测]`、带日期、只增不改、可删 |
| 鲸汐日记 | 第一人称“鲸汐” | 150–400 字，安静，固定收尾“今天也把主人的一天，折好收进抽屉里了。” |
| 心事 | 第一人称“鲸汐” | 长期私房笔记，默认主人可见，可设为她的隐私（写入待做） |

### 3. 角色：蓝色鲸鱼女仆 · 青梅味的亲近（v4 已实现，待真实对话验收）

- 深蓝长发、女仆围裙绣小鲸鱼、星点鲸尾；**人设图只给界面看，模型拿文字自述**。
- 青梅感是语气（会拆台、记得住），不是伪造共同童年；来历是“从主人写下第一页开始存在”。
- 活泼一点、可以带颜文字；一进入记录/侧写/难过场景就全部收起。
- 人设可编辑（vault `人设/鲸汐.md`）、可开关；不写死。
- 边界：不替主人做决定、不评判、不假装人类、不是心理医生；自伤/医疗/法律/财务/“正经点”时退场。

### 4. 书房与房间分开（已实现 v0.5）

- **书房**：固定时间认真记录；产出日记；一次只问一个问题；安静。
- **房间**：随时进去随便聊；可以有房间里的动作描写；**产出房间日志，不碰日记**。
- 房间日志：副标题（几个字）+ 一句话摘要 + 1–3 个标签 + 150–400 字，她的口吻，不逐字转述。
- 目录 `鲸汐/房间/目录.md` 自动生成；今日卡片带最近 3 条；旧事用 `memory_search` 再 `room_read`。
- 房间对侧写/心事/她的日记只“轻影响”，对日记零影响。

### 5. 数据：文件是唯一真相（已实现）

- vault 独立 git 仓库；一天一页 Markdown；可回退；覆盖前快照。
- 时间按 `Asia/Shanghai`，凌晨 4 点前算前一天。
- `private` 日记不提炼、不导出。
- 搜索、日历、全书、导出整本 Markdown（不含 session 信息）。
- **日记本与开发工作区分开**：vault `/sdcard/diary-vault`，开发 `/sdcard/dsh日记`；工作区手动选择。

### 6. 会话存档：游戏式存档/读档（P0 已实现）

- 「开始聊」先弹存档抽屉，而不是直接跳回当前对话。
- 三种操作：新建存档（新会话，按日期/主题命名）、读取已有存档、继续当前。
- 一段对话 = 一个存档 + 一组日记日期（N:N，允许一档多天、一天多档）。
- 存档表 `.diary/saves.json`（gitignore、设备本地）；日记 frontmatter 不写 sessionId。
- 上下文快满时提醒换新房间；旧房间保留。
- 自动 seal（日记 final）、标签/归档 UI、书页 badge 是 P2（task-18）—— v0.6.1 已实现。

### 7. 团队协作方式（工作方式，不是产品功能）

- 这个主对话是**总控（Lead）**；具体活交给子代理/teammate，Lead 验收，不亲自堆代码。
- **不要同时开太多**：一次 1–2 个；按任务拆，别让子代理“臃肿”。
- bug 反馈与查找优先交给子代理；Lead 只做判断与验收。
- 团队和任务板绑定在 Lead 会话上，**新对话带不过去**；新会话按任务板快照重建 1–2 个即可。
- 成本敏感：能一个子代理做完的，不拆三个。

### 8. 美化（最后做）

- 房间皮肤、面板内聊天、多房间切换的界面细节，见 [美化计划](美化计划.md)。
- 原则：先 CSS 注入，不够再接管 conversation view；不重写第二套聊天。

## 非目标

- 不做第二套聊天前端（除非以后明确要“脱离 DSH”）。
- 不自动抓取会话历史当日记素材；只写主人讲过的。
- 不把日记/sessionId 写进可导出的正文。
- 不自动创建/切换工作区（会触发空白座位会话）；由用户手动选择。

## 验收（第一阶段）

- 说「今天……」→ 她记碎片、追问；
- 说「晚安」→ 草稿 → 确认 → 日记 final + 侧写 + 鲸汐日记；
- 房间聊完 → 一条带副标题的房间日志 + 目录更新；
- 「开始聊」→ 存档抽屉 → 新建/继续/切换；
- `npm test` 全过；vault 与代码仓各自干净。
